# Abi Birthday Website

## GitHub upload (no assets folder needed)
Upload **all files in this folder directly into the repository root**. Keep `index.html`, all `.jpg` / `.png` images, `special-song.mp3`, and `background-song.mp3` together at the same level. Do not create or upload an `assets` folder.

## Music behaviour
- `special-song.mp3` — Chellame Magale (Mohan Kannan Version), shown in the Special Song card.
- `background-song.mp3` — Annana Thaalaattum, starts when the visitor clicks the entrance page button and loops through the website.
- Playing the special song pauses the background song. Pausing or finishing the special song resumes the background song.

## Enable GitHub Pages
1. Open the GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and open the displayed website URL.

All media paths are relative filenames in the repository root.
